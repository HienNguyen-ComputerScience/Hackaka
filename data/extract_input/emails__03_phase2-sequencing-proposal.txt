Hello both,

Following our conversation, a proposal for how we sequence Phase 2.

Rather than delivering all four fresh categories together in one go-live, we would
deliver produce and dairy first, then chilled ready meals, then bakery. Three smaller
go-lives roughly six weeks apart.

The advantage is that value starts landing earlier and each wave de-risks the next. The
disadvantage is more cutover events and a longer total elapsed time, which I know is in
tension with the twelve-month window.

If this works for you we would build the plan around it. Happy to discuss.
